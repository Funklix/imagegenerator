# Speaker Image Generator

A small event tool for creating branded speaker assets from a predefined event template.

## Prerequisites

- Node.js 20.9 or later
- npm

## Getting started

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Project scope, architecture, development principles, and workflow are defined in
[`PROJECT.md`](./PROJECT.md), [`ARCHITECTURE.md`](./ARCHITECTURE.md),
[`AGENTS.md`](./AGENTS.md), and [`WORKFLOW.md`](./WORKFLOW.md).
